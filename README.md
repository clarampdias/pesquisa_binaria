## 📌 Exercícios Propostos

### 1. Atividade 1 (`atividade_1.py`)
* **Enunciado:** Quantos números primos são menores que 67?
* **Descrição:** Aplicação do algoritmo de **Pesquisa Binária** em uma lista ordenada de números primos para localizar o índice do valor 67. Como a lista é indexada em 0, a posição encontrada equivale à quantidade exata de números primos inferiores a ele.

### 2. Atividade 2 (`atividade_2.py`)
* **Enunciado:** Qual o nome associado ao número 256 e quantas tentativas foram feitas? Quantas tentativas seriam em uma pesquisa sequencial?
* **Descrição:** Busca pelo número 256 em uma lista ordenada de tuplas no formato `(numero, nome)` comparando o desempenho entre a **Pesquisa Binária** e a **Pesquisa Sequencial**.

---

## 📊 Resultados Obtidos (Atividade 2)

| :--- | :--- | :--- |
| **Pesquisa Binária** | Simone | 5 |
| **Pesquisa Sequencial** | Simone | 39 |
